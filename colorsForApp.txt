HR APP THEME COLOR SYSTEM
==========================

Apply each theme to the WHOLE application, not only the background.
All backgrounds, sidebar, cards, text, icons, borders, inputs, buttons,
metric cards, quick actions, tables, badges, shadows and focus states
must use theme tokens.

SEMANTIC METRIC COLORS:
- Total Employees = primary
- Present Today = success
- On Leave Today = warning
Do not hard-code purple/green/orange metric cards across all themes.

IMPLEMENTATION
--------------
Create centralized theme tokens, e.g.:
background, sidebar, primary, primaryDark, secondary, accent,
card, cardSoft, text, textSecondary, border, success, warning,
danger, glow.

Every component must consume these tokens. No hard-coded theme-dependent
colors. Preserve semantic colors (success/warning/danger) while allowing
their exact shades to vary by theme.

For light themes, use white/off-white surfaces with dark text.
For dark themes (especially Midnight/Obsidian), use dark cards and light text.
